# 📚 SnapStudy

SnapStudy is an AI-powered study assistant that helps students understand and revise their study materials using Generative AI.

Students can upload images of handwritten notes, textbook pages, diagrams, or questions. They can also type questions directly and receive simple, clear explanations.

## 🚀 Features

- 📸 Upload study notes and textbook images
- 🤖 AI-powered explanations using Google Gemini
- 📝 Summarize study materials
- ❓ Ask questions and get answers
- 🧠 Generate important concepts and key points
- 📖 Identify important definitions and formulas
- 🎯 Get possible exam questions
- 📲 Send revision summaries to Telegram
- 💬 Interactive AI study chat

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Python Telegram Bot
- Generative AI
